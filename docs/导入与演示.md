# 导入与演示 · v0.3.0

## 导入

1. 下载 [v0.3.0工程ZIP](https://github.com/ZamZheng/Battle-for-A-MEETING-/archive/refs/tags/v0.3.0.zip)，完整解压，在微信开发者工具导入含 `project.config.json` 的根目录。
2. 工程保留已测试AppID、编译设置及基础库3.17.5。仅使用有权限的开发者账号，其他开发者可换用自己的AppID；工程不含AppSecret。
3. 点普通编译，无需安装依赖、构建npm或开通云开发。首页为 `pages/home/home`。
4. `miniprogram/components/date-time-picker/` 四个文件必须齐全；`miniprogram/pages/edit-info/` 四个文件也要保留。直接完整解压导入即可，不要再逐个套用本轮旧补丁。
5. 新导入不携带wx本地缓存中的会议、投票、头像。要继续原模拟数据，请保留原工程和缓存；工程ZIP不能充当数据备份。

当前仅本机模拟。不同手机不能通过模拟路径共享同一会议；切换测试身份不是真实微信登录。GitHub下载到的代码仍需微信开发者工具编译，云端Node测试不是微信审核或真机测试。

## 完成一场会议

1. 首页保持模拟发起人，创建会议，填写主题、目的。
2. 选择明天或更晚的预计日期，点蓝色“添加此日期”。添加后变灰，可多选/移除。设置每日范围、时长、候选开始间隔。
3. 日期显示（周几）；所有时间按北京时间计算。弹出滚轮字体1.5倍，分钟00/10/20/30/40/50。关闭状态和页面时间保持普通字号。选项取消不提交，点确定才写入栏位；既有非10分钟值不自动改写。
4. 回复截止晚于现在且不晚于最早初始候选，默认明天08:00。调整候选日期时一并检查。
5. 名单逐行填写成员和备注，两栏分开，无需分隔符；每行可选必到/可选及上移、下移、删除，底部添加。至少一位必到、称呼唯一、最多30人。发起人也参会时要把自己列入。
6. 生成预览、选择保留候选并发布。校验错误会弹OK、红色虚线框并在确认后定位栏目，开始编辑清除标记。发布成功先显示邀请卡，确认复制成功两秒后回首页。
7. 首页切换模拟成员甲，粘贴本机邀请进入。先选头像再点角色，确认后进入协调页。未选头像会弹窗，取消/失败清除无效选中，头像为圆形。旁听者在同一列表最后。
8. 对每个候选选择可以、可协调或不行，可批量操作；点提交才进入汇总。一般参与者成功后点OK回首页，高亮刚更新会议。再次进入只读，主动点修改才编辑。刷新保留当前页草稿，退出页面仍丢弃未保存内容。
9. 换模拟成员乙、丙等完成认领和提交；已提交者直接进入详情。参会发起人也要认领并提交，未提交提醒同样适用。
10. 发起人查看回复及待补名单，收齐后右上“锁定时间”，选择一个未来且无人选不行的时段。可以/可协调都可锁定，可选成员的不行也排除。锁定校验最新版本，期间变动会要求刷新。
11. 最终安排输入网络会议链接（选填），点“确认并复制会议通知”。先校验保存，再复制：会议主题、参会名单、时间、网络链接、查看最终会议安排。通知不含目的；其他成员可以查看和复制已保存链接。

## 全部不行的出口

- 当前已知选项全部不行后提交，弹出补提窗口，显示会议时长和日期/开始时间，结束自动计算；每次最多一个。
- 新建议须在未来，可以早于回复截止，允许超出初始日期和每日范围。相同起止复用，不同建议累加，总候选最多80。
- 补提者记可以，原有答案保留；其他成员只补答缺失的新项。两人拿旧页面连续提交建议都能追加，后提交不会覆盖先提交。
- 原回复已交但新增时段未答时，首页显示个人红色补选标签，本人正式补齐即消失，不等待他人。发起人的全局待补短称呼只在详情中显示。
- 全员对新增时段也补齐后才能锁定；首页仅发起人显示绿色已收集完毕，锁定/取消后隐藏。全部回复不保证一定存在无冲突时段。
- 建议标签显示原提议角色的当前短称呼，更正该角色名字后同步；角色被删除时保留最后可查称呼，不冒认新人。

## 修改会议信息

收集中发起人可在修改身份旁点“修改会议信息”，独立页预填主题、目的和逐行名单，没有时间选项。改名/备注/顺序保留角色ID、头像和投票；新增成员须认领回复；删除已认领者在保存前确认转旁听，原选择保留但不汇总。编辑期间他人新增投票或建议保留，同一份元信息被其他编辑页改过时拒绝旧保存。其他成员重新进入/刷新读取新信息，不发送通知。

截止后先延长重新开放再修改。锁定/取消后不可编辑这些信息、改票或更改身份；改期用新一轮。新一轮只预填主题、目的、时长及分栏名单，日期重新选，旧会保留，新会没有旧绑定和投票。

## 首页与工具

首页邀请入口第一、创建第二、我的会议最后。会议列表内部滚动，约四条高度；状态单独较大灰字，更新时间无星期，右上蓝色发起人标签，状态行右侧绿色收齐标签，更新时间右侧个人红色待补标签。

发起人工具的身份更正区域最多三行内部滚动，不能覆盖已占用角色。撤销邀请阻止新人，已加入者保留访问。复制排查信息按钮仍保留在无可锁定结果时，是否移除待后续决定；只复制调试文字，不发送或改数据。常见工具提示见[排障说明](开发者工具排障.md)。
