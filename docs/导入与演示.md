# 导入与演示 · v0.2.0

## 从GitHub下载后打开

1. 下载固定版本 [v0.2.0 工程ZIP](https://github.com/ZamZheng/Battle-for-A-MEETING-/archive/refs/tags/v0.2.0.zip)，先完整解压。
2. 在微信开发者工具选择“导入”，目录选含 `project.config.json` 的根目录。小程序源码在 `miniprogram/`，不要只导入它，也不要把整个工程拖进已有的源码文件夹。
3. 工程沿用用户当前测试的AppID、项目名、编译设置，基础库为3.17.5。同一开发者账号可继续测试；其他开发者使用自己有权限的AppID。AppID不是AppSecret，工程不含AppSecret。
4. 选择普通编译，入口为 `pages/home/home`。无需安装npm依赖、构建npm或开通云开发。
5. 首页依次是“有会议需要协调时间？”、“想发起一场会议？”、“我的会议”。保留已有工程继续测试时，不要清除Storage；从ZIP导入不能恢复以前的本地会议和头像。

`project.private.config.json` 是开发者工具在本机生成的配置，不纳入Git。全新导入时公共配置即可使用；已有工程的私有配置可能覆盖基础库等设置，可在工具详情中核对。所有数据操作目前只调用本机wx存储，没有数据库、云函数或跨设备同步服务。

## 完成一场模拟会议

1. 首页选择“模拟：发起人”，点“发起会议协调”，填写主题和目的。
2. 选择明天或更晚的日期，点击蓝色“添加此日期”；添加后按钮变灰。设置09:00—12:00、时长60分钟、候选间隔30分钟。
3. 回复截止必须晚于现在且不晚于最早候选。默认明天08:00，调整日期时一并核对截止。所有时间统一为北京时间。
4. 名单每行一人，例如“甲：主持”“乙：技术建议”“丙”。冒号后的备注只在身份认领选项显示，其他页面仅显示称呼；称呼不得重复。行末问号表示可选，但当前锁定规则仍要求其提交且在目标时段没有“不行”。发起人如参会，也须在名单内并认领。
5. 生成候选并删选后，点击“生成会议邀请”。邀请卡显示主题、实际保留的候选时段、人员和模拟路径。点“确认复制邀请链接”，复制成功后停留两秒回首页；复制失败可重试，不会重复创建。
6. 在首页切换为“模拟：成员甲”，粘贴刚复制的路径并进入会议。先选择头像，再点角色“甲”，在确认弹窗中确认后进入协调页。没有姓名/昵称输入框。旁听者位于角色列表最后。
7. 进入第二步时未提交提醒位于热力卡最上方。参考汇总后，选择每个候选的“可以”“可协调”或“不行”，也可使用三个批量按钮。点击提交才保存；草稿不会进入汇总。
8. 参与者提交成功显示感谢弹窗，点OK才回首页；刚更新的会议在“我的会议”中浅蓝高亮。再次进入为已提交只读详情，点击“修改时间判断”才进入编辑，可保存或取消。
9. 在首页切换“模拟：成员乙”和“模拟：成员丙”，各自通过邀请认领并完整提交。让至少一个时段无人选“不行”，可以全是“可协调”。旁听者不计票。
10. 切回“模拟：发起人”，打开自己的会议。发起人可看回复进度、未回复名单，以及各时段可协调/不行人员；标题右侧出现“锁定时间”。点击后选择未来且无人选“不行”的候选，锁定成功后定位到最终安排。
11. 在最终安排粘贴网络会议链接（选填），点“复制会议通知”。系统先保存链接再复制带链接的通知。其他成员可查看已保存链接和最终安排。

发起人默认可直接管理会议，不强制参会；要投票，先点“修改我的身份”认领名单角色，未提交时同样有蓝色提醒。首页本人创建的会议带“你是发起人”标识。切换身份只是本机测试工具，不是微信登录；模拟邀请不能发送到另一台设备共享本机会议。

## 常见边界检查

- 已回复人数按名单成员完整有效提交计算，旁听者不计入分母。未认领/未提交/部分旧回复不会算作已收齐。
- 全部回复后，即使候选都冲突也可打开锁定窗口；窗口会解释为什么没有可选时间，不会强行锁定。
- 任何名单成员选“不行”，热力图优先红色且比例越高越深，该时段不进入锁定选项。没有“不行”时按“可以”比例显示绿色。
- 发起人协助更正按成员逐行操作，最多显示三行，更多成员内部滚动；已占用角色不能覆盖，会弹窗提示。头像与已提交选择随账号迁移。
- 截止后不能改票；发起人可延长到未来且不晚于最早候选后重开。截止后仍可锁定合格且尚未开始的时段。
- 锁定使用打开窗口时的版本，期间有人更新回复会拒绝旧快照。锁定/取消后禁止改票和更改身份。
- 新一轮预填主题、目的、时长和名单，日期重新选，不沿用认领与回复。旧会议保留，取消须显式操作。
- 撤销邀请阻止新访客，已加入者保留访问；清空本机模拟数据不可恢复。
- 保存失败不能提示成功，复制失败可重试。常见工具提示见[排障说明](开发者工具排障.md)。
