# 多人会议时间协调 · 微信小程序

原生微信小程序，当前版本 **v0.2.0 · 2026-11-07 本地模拟验收版**。以用户上传并确认运作正常的 `meeting-avatar-A03.zip` 为基线，23个小程序文件与该压缩包一致。

本版的功能、检查结果及下一轮续接事项见 [版本交接](docs/版本交接-2026-11-07.md)。固定版本下载：[v0.2.0 工程 ZIP](https://github.com/ZamZheng/Battle-for-A-MEETING-/archive/refs/tags/v0.2.0.zip)。

创建完整候选 → 分享邀请 → 主动选择头像 → 自助认领角色、无需审批 → 参考热力图填写 → 汇总协调 → 名单成员全部提交后，发起人从无“不行”票的候选中选择并锁定；无交集则继续协调或开启新一轮。

## 开始试用

1. 在微信开发者工具中导入本仓库根目录，识别 `project.config.json`；源码位于 `miniprogram/`。
2. 工程保留本机测试使用的 AppID、项目名及编译设置，基础库固定为 **3.17.5**（原本保存在本机私有配置中）。同一微信开发者账号可继续使用；其他开发者需使用自己有权限的 AppID。
3. 不需要安装 npm 依赖、不需要“构建 npm”，也不需要开通云环境。点编译进入首页。
4. 依照 [导入与演示说明](docs/导入与演示.md)完成一场模拟会议。

用户已在微信开发者工具中完成多轮测试，并确认本版运作正常。云端对上传的小程序代码运行最新95项业务/模拟控制器测试，全部通过；云端没有运行微信开发者工具，尚无真机或真实多人联调证据。

## 当前能力与边界

- 创建多日期候选，时长与开始间隔独立，发布前可删选。
- 名单每行一人，支持“称呼：备注”；备注仅在认领选项显示，其他位置只显示称呼。
- 独立认领页只放头像和角色列表，旁听者在列表最后；点角色、弹窗确认后进入会议详情与时间协调页，未回复不算可以。
- 名单全员完整回复后可打开锁定窗口；候选接受“可以”和“可协调”，任何名单成员选“不行”均排除该时段，可选成员也不例外。旁听者不投票、不计入回复分母，无逐人审批。
- 自助更正/发起人协助更正角色，选择随账号迁移，不能覆盖已认领角色。
- 创建后先展示邀请卡，确认复制成功后两秒回首页；参与者提交后点OK回首页，并高亮刚更新的会议。
- 已提交者默认只读，可主动修改；发起人逐人更正身份，最多三行内部滚动，不覆盖已占用角色。
- 任意“不行”票使热力块显示红色，随比例加深；发起人可看可协调/不行人员的短称呼。
- 完整填写后提交，截止前修改、延长截止、版本检查后锁定、取消、新一轮；锁定后可填写网络会议链接，复制带链接的通知。
- 本地持久化与5个模拟身份，可验证流程，**不能跨设备共享**。
- 头像由用户通过chooseAvatar主动选择并保存为本地文件，不自动读取或验证微信头像。无需输入姓名或昵称，显示标签来自所认领角色。模拟账号编号不是微信号；此工程没有读取真实微信身份。
- **没有真实云函数、数据库或服务端权限边界；不要发布给真实用户使用。** 本地数据与身份可被调试器修改，客户端测试不能证明后端安全。
- 不发送微信通知；旁听者在小程序内查看最终安排。

工程ZIP保存代码与说明，不包含开发者工具缓存中的会议记录、投票和本机头像文件。继续当前测试请保留原工程和数据缓存，不要把解压后的整个文件夹拖进已有的 `miniprogram`。

## 开发验证

安装 Node.js 22 或以上版本（当前实际验证为 Node.js 24.22.1），执行：

```sh
npm run verify
```

无需下载依赖。检查包含 JS 语法、JSON 配置、页面入口/事件绑定，以及业务规则和页面控制器+模拟存储的流程测试。测试不渲染 WXML、不连接微信、不模拟真正的分布式并发。

## 代码结构

```text
miniprogram/
  pages/home/       我的会议、模拟身份、邀请入口
  pages/create/     创建候选、名单、预览和发布；新一轮
  pages/identity/   选头像、认领角色（独立页面）
  pages/meeting/    热力图、填写、最终安排、发起人工具
  lib/domain.js     无平台依赖的业务规则及读写投影
  lib/store.js      仅用于本地的模拟存储/身份适配器
  lib/ui.js         提示和确认框
scripts/check.js    静态检查
tests/              业务和页面控制器流程测试
docs/               需求决策、验收说明、开发记录和迁移原文
```
