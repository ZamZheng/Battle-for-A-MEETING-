# 多人会议时间协调 · 微信小程序

原生微信小程序第一版本地模拟工程，当前阶段 **M1**。名称暂定，未核验名称可用性。

创建完整候选 → 分享邀请 → 工作姓名与自愿头像/昵称 → 自助认领、无需审批 → 参考热力图填写 → 汇总协调 → 必到人员明确可以后由发起人锁定；无交集则继续协调或开启新一轮。

## 开始试用

1. 在微信开发者工具中导入本仓库根目录，识别 `project.config.json`；源码位于 `miniprogram/`。
2. 当前使用 `touristappid`。若工具提供测试号/游客模式，可用于本地流程；如当前工具要求真实 AppID，请在本地工程设置中填写本人小程序的 AppID。游客模式不保证分享、头像和真机能力。
3. 不需要安装 npm 依赖、不需要“构建 npm”，也不需要开通云环境。点编译进入首页。
4. 依照 [导入与演示说明](docs/导入与演示.md)完成一场模拟会议。

用户已在微信开发者工具中导入，并提供创建、热力图与填写页面的实际运行截图；首次WXML编译问题已修复。最新r4视觉微调仍待完整回归验收，尚无真机或真实多人联调证据。当前云端开发环境没有可用的微信开发者工具、真实AppID或微信云环境。Node测试不等于微信编译验证。

## 当前能力与边界

- 创建多日期候选，时长与开始间隔独立，发布前可删选。
- 认领前匿名热力图，认领后共享具名回复；未回复不算可以。
- 必到角色优先，额外参与者仅看安排、不投票，无逐人审批。
- 自助更正/发起人协助更正角色，选择随账号迁移，不能覆盖已认领角色。
- 完整填写后提交，截止前修改、延长截止、版本检查后锁定、取消、新一轮、复制通知。
- 本地持久化与5个模拟身份，可验证流程，**不能跨设备共享**。
- 头像为用户主动选择的本地文件。模拟账号编号不是微信号；此工程没有读取真实微信身份。
- **没有真实云函数、数据库或服务端权限边界；不要发布给真实用户使用。** 本地数据与身份可被调试器修改，客户端测试不能证明后端安全。
- 不发送微信通知；“仅接收信息”当前指进入小程序查看最终安排。

## 开发验证

安装 Node.js 22 或以上版本（当前实际验证为 Node.js 24.22.1），执行：

```sh
npm run verify
```

无需下载依赖。检查包含 JS 语法、JSON 配置、页面入口/事件绑定，以及业务规则和页面控制器+模拟存储的流程测试。测试不渲染 WXML、不连接微信、不模拟真正的分布式并发。

## 代码结构

```text
miniprogram/
  pages/home/       我的会议、模拟身份、邀请入口
  pages/create/     创建候选、名单、预览和发布；新一轮
  pages/meeting/    认领、热力图、填写、最终安排、发起人工具
  lib/domain.js     无平台依赖的业务规则及读写投影
  lib/store.js      仅用于本地的模拟存储/身份适配器
  lib/ui.js         提示和确认框
scripts/check.js    静态检查
tests/              业务和页面控制器流程测试
docs/               需求决策、验收说明、开发记录和迁移原文
```
